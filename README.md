# ✨ Sobre o Projeto

Este é o **site institucional oficial da Thau Luna Acessórios**, criado para apresentar a marca de forma elegante, delicada e moderna.

O projeto foi desenvolvido com foco em:

💕 identidade visual forte  
✨ experiência encantadora  
🌙 estética feminina e sofisticada  
🎀 conexão emocional com clientes  
💻 navegação moderna e responsiva  

---

# 💖 Conceito da Marca

A **Thau Luna Acessórios** nasceu em **2025** com a proposta de transformar pequenos detalhes em algo especial.

Mais do que vender acessórios, a marca transmite:

✨ significado  
💕 carinho  
🎀 identidade  
🌙 delicadeza  
✝️ fé  
💫 autenticidade  

---

O site foi desenvolvido para:
